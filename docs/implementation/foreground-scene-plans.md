# 主对话同步规划配图

设置 → 场景生图 → 配图提示词来源：独立生图助手（默认）或主对话同步生成。

主对话模式在正常游玩/剧本回合提供 tavern_submit_scene_images 工具。主模型在最终正文（或 submit_story）之前提交 1–6 个场景，各含人物事实/英文 tags 与布局、原句 anchor、视角、比例。工具只校验并将方案写入原生工具结果的 presentationMeta，返回简短回执，不生成图片。该工具不向人物卡编辑或后台 Agent 开放。

正文成功落盘时，宿主只接纳当前原生回合且匹配当前 body operationId 的回执，将方案和最终正文摘要存在该条消息的 foregroundScenePlan 字段；正文文本保持原样。中断/重试回合不会接纳旧 operation 的回执。编辑、Swipe 或重新生成后摘要不同则方案失效。

首次生图时在当前渠道下校验主方案并进入原有计划、参考资料、比例、风格、视角、NSFW、多图队列链路。主方案有效时不调用独立规划 Agent；没有方案、旧方案或校验失败时回退现有助手。关闭每轮自动生图仍保存方案，用户点击后再调用图片服务。手动新增/重新构思继续由独立助手处理。

已验证真实 DSH Agent Loop → 原生工具结果元数据 → 场景计划 → 本地 HTTP 图片服务；验证多图复用、旧正文回退、消息正文不混入方案、索引式历史读取及设置选择。测试不访问用户 API 凭据，也不请求真实模型图片。
