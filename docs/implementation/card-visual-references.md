# 人物卡视觉参考工具

「修改人物卡」中的 Agent 可调用 `tavern_character_reference`。工具仅在卡片工作台暴露和执行；自由游玩与后台结算不获得这项写权限。

- `generate`：用户明确要求画图时传 name、prompt 和 text，使用当前场景生图渠道与画风，一次一人。生成结果显示为会话图片，并自动将图片、稳定外貌文字、完整 generationPrompt 存到卡里。保存冲突仍返回生成图片及错误，只重试保存，不重复生图。不会自动反向改写人物描述。
- `list`：列出卡内参考及当前改卡对话里可用的图片编号。
- `read`：读取指定人物的参考文字，并把保存的图片作为图片内容返回给模型；需选择支持视觉的文字模型才能理解图片。
- `upsert`：按人物姓名保存参考文字、可选英文标签和当前会话图片。必须携带刚读取的参考版本。图片不能引用任意磁盘路径、网址或别的对话的附件。
- `remove`：移除指定人物参考，需要参考版本。
- `update_description`：在用户要求反向修改人物描述时，由 Agent 根据 read 的结果编写完整新描述，同时提交原描述用于检查。也可以在 upsert 中同时保存参考与新描述。无关字段、世界书、脚本保留。

参考保存在人物卡扩展 `dsh_visual_references`，图片内嵌，复制/导出人物卡后仍保留。单图最多 8 MiB，支持 PNG/JPEG/WebP；每卡最多 32 个人物，全部参考最多 24 MiB。工具结果只给摘要，不将 Base64 当提示词打印。

场景规划得到匹配人物的文字摘要；出图前再次将明确的卡片参考应用到人物外貌。图片能力遵循现有渠道支持表：支持则携带参考图，不支持则使用参考文字。无参考人物照常依据卡片与剧情出图，既不弹确认也不强制先生成定妆图。同名多人有歧义时不猜测匹配。

用户示例：“把我上传的图片设为林岚的外貌参考，保存参考文字，再按这个形象修改人物描述，保留原来的性格和剧情。”

验证：真实卡片准备与回合保存链路写入临时文件、导出后图片仍可解码、过期版本/错误原描述/其他会话图片被拒绝、工具仅限卡片模式；场景生成复用参考且无参考和旧等待任务均不阻断。
