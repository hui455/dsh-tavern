# 场景分图、视角与内容开关

首次为一轮正文生成插图时，规划输入提供 sequence（最多 6 张）。Agent 提交主图和 additionalScenes（最多 5 项，每项为正文不同原句 anchor、描述和视角）。每张独立规划、入共享队列、保存到现有插图槽位；失败、取消、关闭开关、正文或渠道改变时停止继续生成。重启不自动续买剩余图片，已有图片不重复生成。手动新增、重画及重新构思不递归扩展序列。

单角色控制默认第一人称，可按剧情需要补充上帝视角；多角色/阵营/世界控制由 AI 按题材选择。规划输入包含此前用户行动供判断；layout 的 viewpoint 和 viewpointReason 随图片保存。新增插图界面可指定自动、用户第一人称、上帝视角，手动指定优先并传入最终渠道提示词。手工编辑提示词重画尊重原始编辑，不另强加摄像机文字。

设置中的 NSFW 内容开关默认关闭，只作为内部内容取舍传给规划模型。开启不主动成人化普通场景；NSFW 标签从实际正负提示词中移除，保留其他画面描述。开关不会执行生图。

验证：多场景按次执行、第二张失败后停止、自动触发不重复、配置持久化、手动视角覆盖、正负请求字段无 NSFW 标签、设置页面切换。使用真实 React + DSH Agent/工具/附件与本地图片接口完成新增上帝视角图片的集成流程；未调用用户的真实模型生图。
