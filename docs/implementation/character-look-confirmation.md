# 人物参考资料与场景生图

当前流程不再等待人物确认，也不自动弹出定妆对话。已有的外貌参考会复用；没有参考时直接按人物卡与当前剧情出图。历史形象记录保留，不能因为缺少记录而阻止出图。

已接入参考图的渠道可使用有效图片；不支持或参考图不可用时使用外貌文字。已绑定的普通造型参考不会被空的人物档案覆盖。不同服务的图片授权范围沿用已有校验。

旧版停在 awaiting-characters 的任务，在正文下方显示“继续生成插图”，继续时直接使用已保存方案，不再开启确认对话。

验证包括无参考直接生成、文字与图片参考复用、真实 DSH Agent 和附件存储，以及历史数据恢复。测试图片来自隔离适配器，不代表真实渠道的画面质量验收。
