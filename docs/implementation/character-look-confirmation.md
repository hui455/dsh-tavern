# 人物形象确认

在「设置 → 场景生图」开启「新人物先确认形象」。此开关对已有安装默认关闭，启用后各游戏分别维护形象记录。

场景方案发现未确认的人物时，保存方案并暂停，不请求剧情图片。正文下方会打开独立的形象确认对话，也可稍后通过「确认新人物形象」继续。玩家可以对话修改外貌、生成定妆图，查看后点击确认；所有人物确认后再点击继续剧情配图。

形象助手使用独立的持久子会话，以游戏和人物身份区分；不复用场景规划子会话，不修改正文或 MVU 变量。修改外貌使旧定妆图失效。确认绑定外貌版本与具体图片编号，旧页面无法确认新生成但未查看的图片。记录、图片和确认均持久保存。

后续配图始终使用已确认的外貌文字。当前图片渠道明确支持身份参考图时，附加发送已确认定妆图；渠道或模型变化时须重新确认使用该服务。超出图片数量/大小限制或图片不可读时，保留文字并返回提示。当前 Krea ComfyUI 工作流仅为文生图，走文字分支；不能把它视作支持图像编辑或参考图输入。已有 Gemini 参考图能力保持原边界。

每次点击生成定妆图只请求一次。未知结果不会自动重发，重新生成须确认。排队期间形象发生变化会停止旧剧情请求。工具草稿只保存内容，不得代替用户确认。

验证：定向服务/配置/后台会话测试；真实 DSH Agent、工具与附件存储集成测试；浏览器走通暂停、修改、定妆、确认、继续以及最终图片加载。模型回复和图片服务使用隔离测试适配器，无真实费用，不以测试图片宣称 Krea 画面质量已验收。

浏览器复验：设置 `DSH_BOOT_MODULE` 为已安装的 `dsh-app-boot/lib/index.js`，设置 `SCENE_BROWSER_LOOKS=1`，运行 `node --expose-internals tests/browser/scene-image-browser-smoke.mjs`。普通场景使用既有行为，不启用该变量即可。
