# ComfyUI 自动画面比例

支持带成对 `bindings.width` / `bindings.height` 的维护者工作流。映射必须指向可达节点的直接整数字段，不能覆盖节点连接；旧工作流保持原尺寸，不推测任意节点语义。

Tavern 的画面比例可选「沿用工作流尺寸」「AI 自动选择」或固定 1:1、2:3、3:2、3:4、4:3、9:16、16:9、21:9。AI 在 `submit_scene_layout.aspectRatio` 或人物参考工具 `generate.aspectRatio` 逐图选择。固定设置优先；自动模式无明确比例时使用方向建议（竖 3:4、横 4:3、方 1:1），均未提供则为 3:4。

编译时保持原工作流宽高乘积附近的像素预算，生成精确比例且宽高为 8 的倍数，最大边不超过 4096。最终宽高记录在任务 generationParameters 中。重试查询已有任务沿用原任务，不再次提交。

本机 krea-adult-dsh-tavern.json 的 EmptyLatentImage 节点 29 已改为直接宽高 864×1152 并添加映射，原比例节点不再是输出依赖。ComfyUI 服务的模型、采样、输出节点保持不变。当前酒馆配置已导入新工作流，启用 auto。

验证涵盖全部比例编译、非法映射拒绝、AI 草稿/正式计划保留比例、真实本地 HTTP 测试服务接收最终宽高、固定设置优先、缺省 3:4、实际 React 设置控件保存。未提交真实模型生图任务。
