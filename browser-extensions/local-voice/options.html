OpenAI 兼容接口，扩展会添加 /audio/speech。本机直接填写 http://127.0.0.1:9875/v1，只需启动 GPT-SoVITS，无需转接服务或 API Key。

密钥只存本浏览器本地，不同步、不注入网页。

字数与缓存

不同角色、接口、模型及凭据独立缓存。少于 12 字只复用相同文字；12–39 字最多差 1 字；更长的句子按阈值匹配，长度比例至少 90%。匹配时忽略空格和大小写；12 字以下保留标点，长句匹配忽略标点；相似缓存会显示实际朗读文字。

每次命中刷新使用时间。连续 7 天未使用自动清理；浏览器关闭期间无法运行，重新启动后补清理。另设 256 MB / 1000 条容量上限，优先保留最近使用的音频。

按协议、域名和端口精确匹配，不支持通配符。留空则所有网页都不显示浮条；仍可在扩展弹窗手动朗读。修改后点击保存生效。

恢复默认角色、500 字上限、92% 相似度和划词栏；保留已保存的接口、密钥、动态音色及缓存。
