# 本地角色朗读 · 浏览器扩展 1.4.0

独立的 Edge / Chromium Manifest V3 扩展，选中文字后显示播放与声音选择两枚图标；直接调用兼容 OpenAI 的语音接口，不需要转接服务。此目录单独安装，不会自动修改酒馆或 GPT-SoVITS 的配置。

## 安装

1. 打开 `edge://extensions`（Chrome 使用 `chrome://extensions`），开启开发者模式。
2. 选择“加载解压缩的扩展”，选择本目录（包含 manifest.json）。已有安装可将此目录内容更新到原加载目录，再点“重新加载”。
3. 刷新要朗读的网页，选中文字后点击播放。点击声音图标切换角色，悬停查看当前角色名。
4. 在扩展弹窗进入设置，填写 API 根地址、模型和可选 API Key；需要时授予自定义地址的访问权限。

默认 API 根地址为 `http://127.0.0.1:9875/v1`，模型 `gpt-sovits`，默认角色 `胡桃_ZH`。这些默认值适用于已注册下述兼容路由的本地角色网站；普通 GPT-SoVITS WebUI 不保证具有这些接口。其他兼容服务请在设置中填写自己的地址、模型及音色。

manifest 内的 key 是保持扩展 ID 稳定的公开密钥，不是 API 凭据。API Key 由用户在设置中填写，仅保存在本地扩展存储中。

## 操作与播放队列

- 两枚 36px 图标，总宽约 86px；浅色/深色跟随系统。
- 每次点击按顺序加入队列，当前一条读完后才处理下一条，缓存命中也不会插队。某条失败后继续下一条，不自动重试。
- 点击页面其他位置或 Esc 收起浮条。停止与清空队列使用扩展弹窗中的停止按钮。
- 已提交的生成在停止后仍可完成并缓存，但不会继续播放；队列不跨浏览器重启恢复。
- 生成显示加载图标，排队状态与字数放在悬停提示中；超长、错误及相似缓存实际原句按需显示。
- 支持普通正文、文本框、键盘选区和内嵌页面。浏览器受保护页面不允许注入，可在扩展弹窗粘贴文本。

## 动态音色与缓存

- 自动发现接口支持的音色列表，也可手动刷新；获取失败时保留已保存的列表。可在设置中维护不提供发现接口的服务音色。
- “恢复默认”恢复字数、相似度与默认角色等偏好，保留接口、密钥、音色列表及缓存。
- 每个角色、接口、模型和凭据独立缓存，默认最多 500 字，超长不截断、不发送。
- 匹配忽略空白、标点和大小写。少于 12 字只精确匹配；12–39 字最多差 1 字；更长文本默认 92% 相似度、长度比至少 90%。相似复用可能读出不同文本，界面会展示实际缓存原句。
- 每次使用刷新时间，连续 7 天未使用后清理；浏览器关闭期间不能清理，重启后补执行。最多缓存 256 MB / 1000 条。

## 可选：接入现有 GPT-SoVITS 角色网站

`adapters/openai_speech_api.py` 为已经有 `list_characters`、`generate`、`GenerateRequest`、`OUTPUT_ROOT` 和 `FFMPEG_PATH` 的 FastAPI 角色网站添加 `/v1/models`、`/v1/audio/voices`、`/v1/audio/speech`。它不是通用官方 WebUI 的自动安装脚本。

将模块放在该网站 Python 文件旁，在应用及以上对象定义完成、启动服务之前注册：

```python
from openai_speech_api import register
register(app, list_characters, generate, GenerateRequest, OUTPUT_ROOT, FFMPEG_PATH)
```

`list_characters()` 需返回 `{"characters": [{"id": "...", "name": "..."}]}`，`generate()` 需返回 `{"audio_url": "/audio/文件名.wav"}`。接口继续调用原网站的生成函数，因此原有排队、模型切换、冷启动、请求去重及空闲释放逻辑仍由原网站管理。需要 Python 3.9+、FastAPI、Pydantic 和 FFmpeg；只在受信任的本机服务上启用。

## 验证

在本目录运行 `npm install`，然后 `npx playwright install chromium`、`npm test`。测试使用隔离浏览器配置和本地 fixture 音频，覆盖真实 MV3 播放、缓存、角色隔离、过期、顺序、错误恢复、动态音色、恢复默认、划词、键盘与明暗窄屏布局。

可选适配器测试：安装 `fastapi`、`httpx` 后运行 `python tests/native-api.py`。FFmpeg 默认从 PATH 查找，也可通过进程环境变量 `FFMPEG_PATH` 指定。

设计与截图见 [设计证据](../../docs/design/local-voice-evidence/README.md)。

## 网站白名单

默认仅允许 `http://127.0.0.1:3081` 和 `http://localhost:3081`。在设置的“允许朗读的网站”中逐行填写源地址（协议、域名、端口），不支持通配符。保存立即生效；留空禁止所有网页触发。恢复默认偏好保留白名单。语音接口访问权限与网站白名单独立，非白名单页面与内嵌页面不会触发朗读，扩展弹窗的手动朗读不受影响。
